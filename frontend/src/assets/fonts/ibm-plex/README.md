# IBM Plex web fonts

Unmodified IBM Plex Sans and IBM Plex Mono WOFF2 files, weights 400, 500 and 600.
Vendored from IBM/plex commit `71f558992315a12ca1f06a2215d57962a1992162`.

Source: https://github.com/IBM/plex/tree/71f558992315a12ca1f06a2215d57962a1992162/packages
License: SIL Open Font License 1.1, retained in LICENSE.txt.

The application serves these files locally; its interface does not require a
Google Fonts request. PDF exports keep their independently embedded report font.
